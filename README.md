# DeepFake Detector - Бинарная классификация лиц

> **Самостоятельная реализация EfficientNet на PyTorch для обнаружения дипфейков. Архитектура с MBConv блоками, SE-механизмами, DropConnect и частотным анализом. Достигает Public Score 0.961 на Kaggle и F1 0.93 на валидации.**

## Особенности

- **Самостоятельная реализация EfficientNet** - архитектура написана вручную на PyTorch без использования готовых библиотечных моделей.
- **MBConv блоки** - инвертированные остаточные блоки с Depthwise Separable Convolutions и Squeeze-and-Excitation (SE) механизмами.
- **DropConnect** - регуляризация, случайно обнуляющая часть residual-соединений.
- **Частотный анализ** - преобразование Фурье добавляет дополнительный канал к RGB, помогая модели улавливать артефакты генерации.
- **Комбинированная функция потерь** - Focal Loss + BCE с весами для борьбы с дисбалансом классов (реальных ~41k, фейковых ~8.5k).
- **Многоэтапное обучение** - последовательная смена оптимизатора, learning rate и весов потерь для стабильной сходимости.

## Архитектура модели

Модель построена на основе **EfficientNet** (между B1 и B2) с следующими ключевыми компонентами:

- **Stem** - начальная свёртка 3x3 (или 4x4, если используется частотный канал).
- **7 стадий MBConv блоков** — каждый блок содержит:
  - Expansion Conv (1x1) для расширения каналов.
  - Depthwise Conv (3x3 или 5x5) с группировкой.
  - SEBlock для канального внимания.
  - Projection Conv (1x1) для сжатия каналов.
  - DropConnect и residual-соединение (если stride=1 и каналы совпадают).
- **Head** - Conv 1x1 + Swish, AdaptiveAvgPool2d, Dropout, Linear-слой для бинарной классификации.

**Ключевые параметры:**
- Количество параметров: **14 млн**.
- Входной размер: **256x256** (RGB или RGB + частотный канал).
- Функция активации: **Swish** (x * sigmoid(x)).

## Результаты

Модель тестировалась на датасете **ML Intensive Yandex Academy** (50k изображений, сильный дисбаланс классов). Обучение проводилось в 3 этапа с изменением гиперпараметров.

| 1    | 0-40  | 5e-4 | 5.0       | 0.0957   | 0.9009 | 0.9388     | 0.8660        |
| 2    | 40-55 | 3e-4 | 5.5       | 0.1015   | 0.9195 | 0.9312     | 0.9082        |
| 3    | 55-75 | 1.5e-4 | 6.0       | 0.1182   | 0.9323 | 0.9359     | 0.9288        |

- **Public Score:** 0.961 (при пороге 0.9)

## Использование

### Классификация одного изображения

```bash
python inference.py --image_path /path/to/face.jpg --weights /path/to/best_model.pth --threshold 0.9
```

Где:
- `--image_path` — путь к изображению.
- `--weights` — путь к файлу весов (скачать по ссылке ниже).
- `--threshold` — порог классификации (рекомендуется 0.9).

**Пример вывода:**
```
Изображение: face.jpg
Класс: Fake
Вероятность фейка: 0.9512
```

### Использование в Python

```python
from inference import predict_face

pred, prob = predict_face("face.jpg", "best_model.pth", threshold=0.9)
print("Fake" if pred == 1 else "Real", prob)
```
